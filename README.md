# 🍹 Catálogo de Drinks

Um catálogo interativo de drinks e coquetéis, desenvolvido com React e Material UI. Explore receitas e descubra novos drinks.

## 🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

- [React 19](https://react.dev/) — biblioteca para construção de interfaces
- [Vite 8](https://vitejs.dev/) — bundler e servidor de desenvolvimento ultra-rápido
- [Material UI (MUI) 9](https://mui.com/) — biblioteca de componentes UI
- [Emotion](https://emotion.sh/) — engine de estilização CSS-in-JS usada pelo MUI
- [ESLint](https://eslint.org/) — linter para garantia de qualidade do código

## 🛠️ Como executar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/lucagarciasantos/catalogo-drinks.git

# Entre na pasta do projeto
cd catalogo-drinks

# Instale as dependências
npm install
```

### Scripts disponíveis

```bash
# Inicia o servidor de desenvolvimento
npm run dev

# Gera o build de produção
npm run build

# Pré-visualiza o build de produção
npm run preview

# Executa o linter
npm run lint
```

Após rodar `npm run dev`, acesse [http://localhost:5173](http://localhost:5173) no seu navegador.
